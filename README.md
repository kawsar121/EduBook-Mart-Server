# 📚 EduBook Mart

EduBook Mart is a MERN Stack based web application designed for students to buy and sell new and used books easily. This platform helps students save money by exchanging books within the student community.

---

## 🚀 Features

- 🔐 User Authentication (JWT)
- 📖 Buy & Sell New and Used Books
- 🧑‍🎓 Student-Friendly Interface
- 🛒 Add to Cart & Checkout
- 🧾 Order Management
- 🧑‍💼 Admin Dashboard
- 📦 Book Category Management
- 🔍 Search & Filter Books
- 📱 Fully Responsive Design

---

## 🛠️ Technologies Used

### Frontend
- React.js
- Tailwind CSS
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js
- MongoDB With Mongoose
- JWT Authentication
